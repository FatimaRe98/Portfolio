# Fatima Rizaee - Professional Portfolio 👩‍💻

A responsive portfolio website showcasing my skills as a **Software Engineer** and **Cybersecurity enthusiast**. Built with modern web technologies and a Node.js backend to demonstrate fullstack capabilities. Designed to impress potential employers and collaborators with clean visuals and functional design.

---

## ✨ Features

- **Responsive Design:** Works flawlessly on all devices
- **Interactive Elements:** Smooth animations and clean UI
- **Contact Form:** Fully functional with backend integration
- **Secure Message Storage:** Contact messages saved in a protected JSON file
- **Node.js Backend:** Manages form submissions and serves static files

## 🚀 Getting Started

### Prerequisites

- Modern web browser (Chrome, Firefox, Safari, Edge)
- Optional: Code editor like **VS Code**
- Optional: Replit account (for live deployment)

### Installation (Local or Replit)

#### 🔧 Replit Setup

1. Go to [Replit](https://replit.com)
2. Create a new Repl using the **Node.js** template
3. Upload project files maintaining this structure:

portfolio/
├── index.js # Node.js server
├── messages.json # Contact message storage (auto-created)
├── public/
│ ├── index.html # Landing page
│ ├── about.html # About me section
│ ├── resume.html # Professional resume
│ ├── contact.html # Contact form
│ ├── css/
│ │ └── style.css # Stylesheet
│ ├── images/ # Visual assets
│ └── script.js # Frontend interactivity
├── resume.pdf # Downloadable resume
└── README.md # Documentation


4. Set `index.js` as the **main file** in Replit
5. Click **Run** or use the shell: `node index.js`
6. Open your Repl at: `https://your-repl-name.username.repl.co`

---

## 🧠 Backend Details

- **index.js** (Node.js server)
  - Serves all static files in the `public/` folder
  - Receives contact form data and stores it in `messages.json`
- **messages.json**
  - Securely stores form submissions
  - Auto-created if not present on first run
